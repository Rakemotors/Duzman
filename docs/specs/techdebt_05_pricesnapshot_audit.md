## Контекст

В docs/TZ.md в Приложении Б зафиксирован known schema drift между DDL и фактической схемой `price_snapshots` (см. блок «Known schema drift (PriceSnapshot, на 19.05.2026)»). Все остальные таблицы Приложения Б используют `asset/ts`. PriceSnapshot — единственный outlier с `symbol/collected_at/price`.

Прежде чем делать миграцию переименования (вариант C: `symbol → asset`, `collected_at → ts`, `price → price_usd` с сохранением `quote_currency/created_at/raw_payload`), нужен audit фактического использования полей в коде.

Цель audit — собрать факты, без правок кода. Никаких миграций, никаких изменений в models/services/tests/schemas. Только новый файл-отчёт.
